# Movie Recommendation System

A Content-Based Movie Recommendation System built using Python and Machine Learning concepts. This project recommends movies similar to a movie selected by the user by analyzing movie information such as genres, overview, keywords, cast and director.

## Project Overview

The objective of this project is to build a movie recommendation system that suggests similar movies based on their content.

The system uses Content-Based Filtering, where recommendations are generated by comparing the features of movies rather than relying on ratings or preferences from other users.

For example, if a user selects a science-fiction movie, the system analyzes its features and recommends other movies with similar characteristics.

## Objectives

- Understand and perform Exploratory Data Analysis (EDA).
- Clean and preprocess movie information.
- Extract useful features from movie metadata.
- Convert textual data into numerical representations.
- Calculate similarity between movies.
- Recommend the top 5 similar movies based on a selected movie.

## Dataset

This project uses the TMDB 5000 Movie Dataset.

Dataset Source: [TMDB 5000 Movie Dataset – Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)

The dataset consists of two CSV files:

| File | Description |
|---|---|
| `tmdb_5000_movies.csv` | Contains movie details such as title, overview, genres, keywords and popularity. |
| `tmdb_5000_credits.csv` | Contains information about movie cast and crew. |

## How It Works

### 1. Data Collection

Load the movie and credits datasets into Pandas DataFrames.

### 2. Data Merging

Merge both datasets using the common `title` column to combine movie details with cast and crew information.

### 3. Data Cleaning

Handle missing values, check duplicate records and select relevant features.

### 4. Feature Extraction

Extract the following information:

- Movie Overview
- Genres
- Keywords
- Top 3 Cast Members
- Director

### 5. Feature Combination

Combine all the extracted information into a single column called `tags`.

### 6. Text Preprocessing

Apply stemming using NLTK's PorterStemmer to reduce words to their root forms.

### 7. Text Vectorization

Use CountVectorizer to convert movie tags into numerical vectors.

- Maximum features: 5000
- Stop words: English

### 8. Similarity Calculation

Apply Cosine Similarity to measure the similarity between movie vectors.

### 9. Movie Recommendation

Create a recommendation function that accepts a movie title and returns the top 5 most similar movies.

## Machine Learning Concepts Used

| Concept | Purpose |
|---|---|
| Content-Based Filtering | Recommends movies based on their features. |
| Feature Extraction | Extracts useful information from movie metadata. |
| Stemming | Reduces words to their root forms. |
| CountVectorizer | Converts text into numerical vectors. |
| Cosine Similarity | Measures similarity between movie vectors. |
